# Edge 网页剪藏到 Obsidian

这是一个 Manifest V3 Edge 扩展，可将网页文字、选中的内容和页面截图保存到 Obsidian
Vault。不需要额外安装 Obsidian 插件，也不需要启动本地网络服务。

## 安装

1. 在 Edge 地址栏打开 `edge://extensions`，启用**开发人员模式**。
2. 点击**加载解压缩的扩展**，选择当前目录。
3. 打开扩展详情页中的**扩展选项**，选择 Obsidian Vault 根目录。
4. 配置目标路径和模板并保存。

## 保存

- 在网页空白处单击右键，选择**保存页面文字到 Obsidian**。内容转为 Markdown，保留标题、段落、列表、引用、链接、代码和表格；页面图片、视频、音频等非文字内容用占位符表示，不会下载。
- 选中文字后单击右键，选择**保存选中文字到 Obsidian**。选区的常见文字格式会转为 Markdown，选中的网页图片会下载到附件文件夹并嵌入笔记；视频等媒体保留为链接或占位符，SVG、画布等无法直接下载的图像会显示占位符。网页自定义 CSS 样式不属于 Markdown 格式，不能保证像素级相同。
- 在网页空白处、选中文字或图片上单击右键，有两种截图：
  - **保存可见区域截图到 Obsidian**：当前标签页看得见的部分。
  - **保存滚动区域截图到 Obsidian**：按住左键从左上向右下拖动；不要松开左键，用滚轮向下延伸到目标位置后松开保存，Esc 取消。跨屏长区域会实际滚动页面逐屏裁剪拼接，避免浏览器超视口截图重复当前屏幕。
  浏览器内置页面（`edge://`）和应用商店页面不支持截图。两种截图共用同一组目标文件、模板和格式设置，文件名分别以 `screenshot-` 和 `screenshot-region-` 开头。

右键菜单后会直接写入 Vault，并打开一个靠近右上角的临时结果窗口提示保存成功或失败。窗口提供 **Settings** 按钮；保存成功时无人操作 3 秒后自动关闭；保存失败时为了能看清原因，保留 10 秒。可拖动窗口，拖动期间会重新计时，之后会记住位置，下次在同一位置出现。目标文件夹和文件会自动创建。内容追加到已有文件末尾；新文件头部仅在文件为空时写入。
页面操作保存网页中的可读文字和结构，不保存原始 HTML 或脚本；页面内的图片、视频和音频使用占位符表示。选区内的图片会另存为 Vault 附件；如果网站阻止读取图片，保存会明确报错，不会静默丢弃图片。扩展声明了 `http`/`https` 主机权限，以便读取用户通过菜单操作的网页内容。

## 配置

目标路径和图片附件文件夹都相对于设置页“Vault 文件夹”所选的文件夹（请选择 Vault 根目录，即包含 `.obsidian` 的那一层），例如 `00-inbox/Web Clips.md`。新文件头部支持直接填写文本，也支持填写 Vault 内 Markdown 模板路径，例如
`_meta/linux.inbox.webcapture`（自动补充 `.md`）。扩展会读取模板并处理
`tp.file.creation_date(...)`、`tp.date.now(...)` 和 `tp.file.title`；其他 Templater
语法不会执行，遇到时会在结果窗口提示错误。内容模板支持
`{{title}}`、`{{url}}`、`{{date}}`、`{{content}}` 变量；截图另有 `{{filepath}}`（图片在 Vault 内的路径）和 `{{filename}}`。`{{date}}` 使用本地时间，格式 `YYYY-MM-DD HH:mm`。多行内容会沿用模板中 `{{content}}` 所在行的引用前缀。

页面保存可选择每次创建新页面（使用网页标题命名，遇到重名时自动加时间戳），或追加到目标文件；也可启用阅读模式正文提取。正文提取会优先识别网页主文章区域，无法识别时回退到整页文字，不读取 Edge 内部阅读视图。

扩展仅在使用右键菜单时读取当前页面，并且只访问用户在设置中明确选择的 Vault
文件夹。文件通过 File System Access API 在本地写入。
