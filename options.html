网页剪藏到 Obsidian

选择 Vault 文件夹，然后配置保存位置和 Markdown 模板。

Vault 文件夹

尚未选择文件夹。

下面所有的文件路径和附件文件夹，都以这里所选的文件夹为根目录。

保存页面文字

启用后会提取网页的主要正文区域；若无法识别，则保存整页文字。这不是 Edge 阅读视图内部内容。

可填写头部文字，或填写 Vault 内 Templater 模板路径（如 _meta/linux.inbox.webcapture）；不带扩展名时自动补 .md。

页面文字会转换为 Markdown，保留标题、段落、列表、引用、链接、代码和表格；图片、视频、音频等媒体以文字占位符表示。可启用阅读模式正文提取以减少导航等页面噪音。

保存选中文字

可填写头部文字，或填写 Vault 内 Templater 模板路径（如 _meta/linux.inbox.webcapture）；不带扩展名时自动补 .md。

选区会保留常见文字格式并转换为 Markdown；选中的网页图片会下载到附件文件夹并嵌入笔记。视频等媒体保留为链接或占位符；SVG、画布等无法直接下载的图像以占位符表示。网页自定义 CSS 样式不属于 Markdown 格式。

保存截图

右键菜单中有两种截图：可见区域和滚动区域，它们共用下面的设置。

图片附件文件夹

相对于上方“Vault 文件夹”所选的文件夹，例如填 images/screenshot 就保存到 所选文件夹/images/screenshot。

追加分隔符

内容模板变量：{{title}}、{{url}}、{{date}}、{{content}}；截图还可使用 {{filepath}}（图片在 Vault 内的路径）和 {{filename}}（文件名）。Templater 头部支持 tp.file.creation_date(...)、tp.date.now(...) 和 tp.file.title。
